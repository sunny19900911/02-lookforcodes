## 任务范围

目标是发现全网上现存的 CECS 编号与版本，逐项寻找合法公开、可实际下载的完整 PDF，并比较质量。原始 81 条检索记录只是已有基线，不是 CECS 全集，也不是检索上限。五个专业组是组织方法，不限制标准类别或编号范围。保留历史正式版本，单独识别征求意见稿、报批稿和编号不明项。

主要交付是可维护的 Excel 链接总表及 JSON 数据底座。保存来源详情页、候选直链、实测后的最终 PDF URL、全部有效备用链接、权限/过期情况及检查时间；本地核验路径只作辅助。不会把所有规范合并成一个 PDF。

## 分工与交流

- catalog：唯一 Excel/主索引写入者；维护规范版本、原始映射、一对多链接及历史证据。
- search：五组检索与全网扩展；记录查询、覆盖范围、目录依据、方法演变和待审队列。
- pdf-audit：实际 GET、解析与抽样目视核验；独立记录版本、完整性、可搜索文字、原生书签、可点击目录及清晰度。
- 主控：每 10 分钟组织三方交流，归纳新增证据、疑问、方法、互相质疑、交叉验证及下一轮试验；统一串行提交和推送。

讨论必须产生可复查的下一步试验，不能代替实际下载审查。没有指定自动化频率以外的新计划；跟进自动化由原对话管理，本主控不重复创建。

## 证据和质量口径

标准现行性与 PDF 可下载性分别管理。标准类型、范围、发布实施时间及废止替代关系需要来源；无法证明则为待核实。CECS 不因来源位于上海而归类为上海地方规范。

来源原文、封面/公告及可复测的文件属性作为事实记录；完整性判断和质量评级是基于这些证据的AI审查结论，不是标准发布方认证。作者观点、用户观点与AI推断须注明主体，不能混同为规范原文要求。

下载状态区分：实测完整 PDF、可下载但完整性待核、仅介绍页、仅预览、仅样章/封面、需登录、付费、失效、本次网络失败未验证。HTTP 200、Content-Type 或 .pdf 扩展名不能单独证明成功。

推荐先满足版本正确与正文完整可读，再比较清晰度、文本搜索复制、原生书签及导航。书签和可点击目录单独统计；OCR 可能有识别误差；后加工书签不得冒充原件自带。使用下载时的 SHA256、大小、页数、检查时间和证据路径支持判断。

不宣称穷尽全网。每轮报告实际覆盖编号/目录范围与日期、检索轮次、核验完整 PDF 数、待核和缺口。
